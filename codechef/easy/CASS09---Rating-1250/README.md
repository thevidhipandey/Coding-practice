## Problem

### Format Specifiers - MCQ

What would be the output of the following code:

```
#include <stdio.h>

int main() {
    int x = 5;
    float f = 3.4;
    printf("%d\n%d", x, f);
}

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-11-11T13:42:20.714Z  

```cpp
#include <stdio.h>

int main() {
    float height = 1.82;
    float weight = 72;
    float BMI = weight/(height*height);
    printf("%f", BMI);
    
    return 0;
}

```
